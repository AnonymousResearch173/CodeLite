# CodeLite

This repository contains the **source code and implementation scripts** used for the reproducibility of the **CodeLite** framework, a lightweight hybrid approach for code classification tasks. All code snippets required to replicate the experiments and analyses described in the manuscript are included in this repository.

Due to size constraints, the datasets used in our experiments are hosted externally and can be downloaded from the following Google Drive link:
[https://drive.google.com/drive/folders/13qcJ9nRyvZDn4Vp1Zu23AetIHlxguIjG?usp=sharing](https://drive.google.com/drive/folders/13qcJ9nRyvZDn4Vp1Zu23AetIHlxguIjG?usp=sharing)
